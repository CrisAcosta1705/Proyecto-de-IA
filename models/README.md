# Modelos

El prototipo utiliza `buffalo_l` de InsightFace para deteccion, alineacion y
embeddings ArcFace. Se descarga en `models/insightface/` durante la primera
ejecucion y no se almacena en Git.

Los modelos preentrenados distribuidos por InsightFace estan autorizados para
investigacion no comercial. Antes de otro tipo de despliegue debe revisarse su
licencia y documentarse la version utilizada.
