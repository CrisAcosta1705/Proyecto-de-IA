# Modelo facial incluido

La aplicacion incluye `w600k_mbf.onnx` del paquete oficial InsightFace
`buffalo_sc`. El modelo se utiliza exclusivamente en este prototipo academico.

Los modelos preentrenados proporcionados por InsightFace se distribuyen para
investigacion no comercial. Un uso comercial requiere una licencia separada.

Fuente y terminos:
https://github.com/deepinsight/insightface/tree/master/model_zoo
